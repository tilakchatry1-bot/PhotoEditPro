# PhotoEditPro

A CapCut-inspired Android photo editor starter app built in Kotlin with Jetpack Compose.

Features
- Select a photo from gallery
- Brightness, contrast, saturation controls
- Rotate and zoom tools
- Filter presets
- Add text captions
- Add emoji stickers
- Export edited image to Pictures/PhotoEditPro

Project setup
1. Open the repository in Android Studio.
2. Let Gradle sync.
3. Run the app on an Android device or emulator.

Notes
- This is a production-ready starter app concept with a lightweight editing workflow.
- For a more advanced production version, you can add crop tools, multi-layer editing, undo/redo, and GPU-based filters.
